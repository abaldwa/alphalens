Momentum Backtest — Data Quality Root Cause Investigation

2026-08-01 · scope: 481 trade-book CSVs, 2005-01-03 to 2026-07-31 (5,353 trading days)
Status: Code fixes implemented and unit-tested. Backtest NOT re-run — per explicit instruction, no re-run until upstream OHLCV data for the affected window is corrected. Everything below reflects the investigation and the engine/frontend changes now in place, not a fresh backtest.

1. Trigger

The live Momentum "Trades" view was found to only ever show open positions, and FY2023-24 showed abnormally high returns on manual review. Investigation traced every FY23-24 trade with an outsized return back to its buy/sell dates and underlying OHLCV data.

2. Root cause: OHLCV ingestion gap, 2024-07-08 to 2024-07-31

Daily ticker coverage in ohlcv_adjusted collapsed from ~1,750 tickers/day to ~88-94 tickers/day for 17 consecutive trading days, then fully recovered on 2024-08-01. MomentumBacktester's price_panel.ffill() had no limit=, so it silently forward-filled the last real price (2024-07-05's close) for every trade whose nominal exit fell inside the gap — for weeks. Verified to 6 decimal places against three of the outlier trades:

Impact: 1,954 trades across 198 tickers used a frozen stale price; affected-trade returns averaged +43% vs. a normal population, with a max of +418% (COCHINSHIP) — fabricated, not real.

FY2019-20 and FY2020-21 were separately checked in full: no coverage gaps found. Their large trade returns (TANLA +1,274%, ADANIGREEN +542%, COFORGE +600%, CGPOWER +610%, etc.) match well-documented real COVID-recovery-era multi-bagger rallies — confirmed via smoothly-varying daily price series with normal ~1,500+ ticker coverage around each exit date, not a frozen-price signature.

5. Not yet done (deliberately)

  • The 2024-07-08–07-31 OHLCV data itself has not been backfilled — the engine now refuses to fabricate a price for that window rather than silently continuing to use the stale one.
  • No backtest re-run has been triggered. All 481 trade-book CSVs / reports currently on disk (and their HTML conversions) still reflect the pre-fix numbers, including the fabricated July 2024 returns.
  • The recurring bulk-ingestion fragility behind both the July 2024 and Jan-Feb 2026 gaps (falls back to the same small ~70-90-ticker subset) has not been root-caused at the ingestion-pipeline level — only the backtest engine's response to it has been hardened.
