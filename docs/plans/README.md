# Plans Directory

Active implementation plans and strategic roadmaps.

## Purpose

This directory contains:
- **Active plans** — Current implementation strategies (not superseded)
- **Roadmaps** — Long-term feature/initiative planning
- **Proposal documents** — Pre-spec brainstorming and exploration
- **Quarterly plans** — Time-boxed project priorities

## Distinction from `specs/`

| **Plans** | **Specs** |
|-----------|-----------|
| How to approach work | What needs to be built |
| Strategy & phases | Requirements & acceptance |
| Timeline & dependencies | Data models & contracts |
| Flexible, evolving | Locked once approved |

## Usage

1. **Create a plan** when:
   - Multiple phases/dependencies exist
   - Cross-subsystem coordination needed
   - Pre-spec brainstorming/exploration
   - Quarterly roadmap definition

2. **Move to spec** when:
   - Plan is finalized and ready for coding
   - Use `/speckit-specify` to formalize

3. **Archive to `docs/archive/`** when:
   - Plan is complete and no longer relevant
   - Decision is captured in specs/ for reference

---

**Convention**: Plans use `.md` format. If a plan needs versioning or multi-document structure, organize it in a subdirectory (e.g., `docs/plans/ml-adapter-integration/plan.md`, `research.md`, `decisions.md`).
