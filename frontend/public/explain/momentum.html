Overview

What it is

Momentum is deliberately the simplest strategy in AlphaLens — no ML model, no signal threshold tuning, just trailing price return ranked within a fixed universe and rebalanced on a schedule. That simplicity is the point: it's the strategy easiest to reason about and stress-test, and its backtest engine (backtest/momentum_backtest.py) was the first to get calendar-day CAGR/XIRR methodology, later generalized into the unified Backtest module's core/metrics.py.

features/momentum_universe.py

Universe — fixed market-cap-rank bands

Constituents are fixed on the first real trading day of each year and never recomputed mid-year, even if ranks shift — a stock's rank a decade ago is what decided its band membership at the time, not its rank today.

features/momentum_signal.py

Trailing momentum signal

trailing_momentum() computes each ticker's percentage price return over a trailing lookback, ending at the most recent real close on or before the as-of date — 3/6/9/12 real months, approximated as 63/126/189/252 trading days at the codebase's standard 21-trading-days-per-month convention.

  1. Independent rankings. Each of the 4 lookbacks is its own ranking — never blended into a composite score, per ML38's confirmed scope.
  2. top_n_by_momentum() selects the top-N tickers within a band for a given lookback's ranking.
  3. orthogonalize_momentum_vs_factors() can strip out correlation with other known factors, so a momentum ranking isn't secretly just re-discovering a size or value effect.

backtest/momentum_metrics.py

Metrics — ML38's confirmed 3

ML38's scope deliberately kept the tracked metric set small and specific — not the full Backtest scorecard — per an explicit 2026-07-14 user decision:

MetricBasis
Total ReturnNet-of-cost, whole-run, per variant
CAGRCalendar-day/365.25 over the real elapsed experimentation period — the methodology later adopted as the Backtest module's canonical primary CAGR
Churn FactorBought + sold count per rebalance, reported both as a per-rebalance series and an annualized average

xirr() was added later (also 2026-07-14) specifically for SIP comparisons — plain CAGR only handles a single lump sum in/out, so a monthly-SIP variant needs the money-weighted rate instead.

Roadmap

Status & unification

Momentum currently has its own standalone backtest engine (momentum_backtest.py) and a separate manual trade journal, built the same week as ML38 shipped. Per BacktestUmbrellaPlan.md, both are slated to fold into the unified Backtest module: the signal logic (trailing_momentum_from_panel) stays, but portfolio/SIP/metrics delegate to the shared core/ modules, and the manual trade journal migrates onto the same paper-trading schema Technical, Fundamental, and ML already share — accepting some workflow migration so all four channels end up on one consistent paper-trading UI instead of Momentum staying a special case.

Research artifacts. Momentum's 732-variant grid backtest ledger and year-on-year report are published as standalone Claude artifacts rather than local dashboard screens — linked directly from the Momentum nav section.
