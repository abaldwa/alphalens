Overview

What it is

Fundamental Analysis has no separate feature-computation pipeline of its own. The 28 fundamental ratios (features/fundamental.py) and 12 governance features (features/governance.py) are already computed daily and merged into the same feature Parquet matrix_builder.py writes for every other consumer. What's genuinely Fundamental-specific is a small composite/peer-ranking layer, features/fundamental_composites.py, called at API-request time — not persisted as new columns, since there's no new ground-truth data involved, just documented arithmetic over values already computed.

Inputs

Raw inputs — 28 + 12 features

Every ratio here is sector-relative z-scored, not an absolute cutoff — a positive quality score means "better than sector peers," not "ROE above some fixed bar."

Weights are documented, not backtested. Same standing as this codebase's other composite scores (e.g. Forensic's classical formula weights) — a starting point flagged for revision once enough labeled outcomes exist, not a tuned model output.
Cross-sectional

Peer ranking

select_peers() finds comparable companies (same sector, similar market-cap band) so the Peers and Sector screens can show a stock's ratios in context rather than in isolation — the whole reason the underlying scores are sector-relative in the first place.

Presets

Screener presets

matches_screener_preset() evaluates a stock's ratio set against named preset criteria (e.g. quality/growth/value archetypes) for the Fundamental Screener screen — the same "named, documented condition set" philosophy as Technical Analysis's 42 templates, scaled to fundamentals.

Experimentation

Exit criterion

Fundamental screener presets are entry rules only; exit runs through the same 6-variant system as Technical (baseline stop/target, condition-based, combined, trailing, ATR-adaptive, regime-conditional). Baseline stop%/target% is set per preset: quality_compounder stop 8% / target 20%, garp stop 6% / target 15%, turnaround stop 10% / target 25% — wider than Technical's, reflecting the longer hold typical of a fundamental thesis.

Like Technical, this is experimentation mode — the 270-job backtest matrix (45 strategies × 6 exit variants) decides which Entry+Exit pairing wins per preset. See the Exit criterion system reference → for the full variant breakdown, and the live /backtest-experiments page for current per-run results.
