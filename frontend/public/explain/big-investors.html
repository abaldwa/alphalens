Overview

What it is

A raw bulk/block deal row just says a name bought or sold shares — the hard part is knowing that name is the same real investor as three slightly different spellings elsewhere, and whether their position actually grew. datastore/api/routers/big_investors.py exists to turn scraped raw deals into that answer.

NSE bulk/block deal disclosures — the BSE equivalent API was retired in 2026-07 with no working replacement found (SPEC-PIPE-008), so this channel is NSE-only going forward.

Identity resolution

Family resolution — same investor, different spellings

The genuinely hard problem here is entity resolution: "Rakesh Jhunjhunwala," "R Jhunjhunwala HUF," and "Rakesh Radheshyam Jhunjhunwala" are the same underlying investor. The router builds this mapping with a documented fuzzy-matching pipeline, not a black-box name similarity score:

  1. Tokenize — _name_tokens() normalizes a disclosed holder name into comparable tokens.
  2. Jaccard similarity — _token_jaccard() scores token-set overlap between an unmapped name and known investor families.
  3. Positional abbreviation check — _is_positional_abbreviation_match() catches cases like "R Jhunjhunwala" matching "Rakesh Jhunjhunwala" that pure Jaccard would miss.
  4. Fuzzy family assignment — _fuzzy_match_unmapped_family() assigns the disclosed name to an existing family ID, or flags it for manual reconciliation if no confident match exists.
  5. Position & WAC computation — _position_and_wac_asof() aggregates a resolved family's combined quantity and weighted-average cost across all their tickers, as of a given date.
EndpointWhat it returns
GET /bulk-deals/families/entries-exitsEntries/exits rolled up to resolved investor families rather than raw disclosed names
GET /bulk-deals/families/{ticker}Family-level position history for one stock, with combined quantity and weighted-average cost

MF holdings movers

_mf_movers_rows() compares each fund's holdings across the latest two available months (_latest_two_months()) to surface the biggest net buyers/sellers per stock — same institutional-flow features that feed the ML feature matrix (mf_new_entry_count, mf_total_holding_change_1m, etc.), presented here as a browsable screen rather than a model input.

EndpointWhat it returns
GET /mf-holdings/moversUniverse-wide ranking of month-over-month MF holding changes
GET /mf-holdings/{ticker}Per-scheme holding history for one stock
Human-in-the-loop

Reconciliation queue

Fuzzy matching doesn't resolve everything — low-confidence family matches land in a reconciliation queue rather than being silently guessed.

EndpointWhat it does
GET /reconciliationLists unresolved name-matching cases awaiting a human decision
POST /reconciliation/{log_id}/resolveRecords the human's family-assignment decision, which feeds back into future automatic matching
Also referenced from Momentum's rollout: Trendlyne's public Superstar Investors index provides a free, independently-sourced list of named HNI holdings per quarter, used to cross-check the family resolution above rather than relying solely on NSE's raw disclosure names (SPEC-BIGINV-004).
