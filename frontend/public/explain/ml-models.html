Overview

What it is

systems/ml_signal_engine/ is System 1 in the platform architecture. It's not one model — it's a pipeline of 16, each with a narrow, named job (SOLID Single Responsibility), each inheriting a shared contract (IModel/IClassificationModel/IRegimeModel/ISurvivalModel in contracts/interfaces.py), trained exclusively via walk-forward validation on real data — never a random time-series split, never synthetic training data.

Production

The daily inference chain

Every model runs in a fixed order once per pipeline cycle (today's date only, never backfilled for inference) — the exact order the Backtest module's day-by-day simulation reproduces, so a backtest genuinely mirrors production:

  1. M-01 HMM classifies today's regime.
  2. M-06 P&D pre-filters — blocks any ticker scoring > 60 before a buy signal is considered.
  3. M-02/03/04/05 generate signal + meta-label + conformal interval for the allowed universe.
  4. M-07 Exit scores every currently held position.
  5. Alerts & outputs are written; retrain schedule is checked.
  6. Monday only: M-08 Multibagger weekly scan runs after the daily pipeline.
