Build Order

Phase 1 — Weeks 1–14 · Core Signal Engine
Goal: System usable for paper trading by Week 8
  • Data pipeline: bhavcopy download, corporate action adjustment, 76 technical features
  • Walk-forward backtesting framework with cost model and integrity rules
  • M-01 HMM Regime Detection
  • M-06 P&D Detector (build before signal models)
  • M-02/03 Signal Models 5d and 21d (LightGBM + CatBoost)
  • M-04 Meta-Labeler
  • M-05 Conformal Prediction (MAPIE ACI)
  • M-07 Exit Signal Model + CoxPH survival
  • M-16 PSI Drift Monitor (build alongside first models)
  • SCR-01 Daily Dashboard (basic version)
  • Optuna HPO + SMOTE + threshold optimization for all Phase 1 models
Phase 2 — Weeks 12–24 · Fundamentals + Multibagger
Overlaps Phase 1: fundamentals data flowing by Week 12
  • Screener.in data pipeline + BSE shareholding + AMFI MF holdings
  • 28 fundamental + 12 governance + 12 MF + corporate action features
  • M-03b Signal 63d (adds fundamental features)
  • M-08 Multibagger Detection Model (weekly)
  • M-09 Forensic Classical Scores (formula-based, no training)
  • M-10 Forensic ML Ensemble (12 sector-specific models)
  • SCR-02 Multibagger Watchlist + SCR-03 Forensic Dashboard
Phase 3 — Weeks 24–36 · Deep Learning Ensemble
Only after Phase 1–2 are stable and paper-trading
  • M-11 TFT (pytorch-forecasting) — ensemble member only
  • M-12 BiLSTM + Mamba-2 — sequential patterns
  • M-13 Stacking Meta-Learner — combines all base models
  • M-14 TabNet — feature selection validator (research only)
  • Advanced features: wavelet, entropy, Hurst, pattern recognition
Phase 4 — Week 36+ · RL Meta-Agent
Prerequisite: 3+ months paper trading from all Phase 1–3 models
  • M-15 PPO Reinforcement Learning — position sizing meta-agent
  • 5-stage bootstrapping before any live deployment
  • Replace rules-based position sizer with RL
